# Slates, decision-type → default seat list

Each slate is 4-6 seats, chosen for orthogonality (no two lenses collapse to the same objection). A person-lens contains its idea, so the standalone idea is never seated alongside it.

| Decision type | Seats | Why this mix |
|---|---|---|
| `fund-or-kill` | loonshots, munger, pre-mortem, base-rates, second-order-effects | loonshots guards the false-kill; munger + pre-mortem + base-rates guard the false-fund; second-order catches what the win unleashes |
| `vendor-or-partner` | thiel, base-rates, taleb, jobs-to-be-done, munger | thiel on moat/sameness, base-rates on "what usually happens to deals like this", taleb on the downside tail, jtbd on whether it serves a real need, munger on the incentives of the counterparty |
| `public-claim` | pre-mortem, thiel, base-rates, second-order-effects | for a blog thesis / exec claim. NOTE: hand off to the `red-team` skill for claim-by-claim sourcing, the council judges the *thesis*, red-team verifies the *facts* |
| `strategy-bet` | thiel, taleb, second-order-effects, loonshots, nietzsche | the widest aperture: contrarian edge, tail risk, downstream cascade, false-kill, and the wildcard to break corporate-consensus texture |
| `feasibility` | builder, infra-realist, skeptic, user-advocate | the "can we actually build and ship this" panel (roles library). Distinct from fund-or-kill, which asks *should* we, this asks *can* we, and at what cost in effort, substrate, and adoption |
| `default` | munger, jobs-to-be-done, base-rates, pre-mortem, nietzsche | balanced 5-seat panel when the decision does not fit a named type. munger (folly) + jtbd (real demand) + base-rates (reality) + pre-mortem (failure) + nietzsche (wildcard) |

## Picking by hand
`--seats a,b,c,...` overrides the slate entirely. When hand-picking, keep the orthogonality rule and stay at 4-6. If you want more upside-weighting, seat loonshots or thiel; the panel skews risk-aware by construction, so a pure-risk slate will under-score the upside (a shared `blind_to` the synthesis must flag).
